When doing anything use subagents to gather necessary information about the codebase.

When implementing new features or fixing bugs always use subagents first to do design work/planning, then use subagents to do the coding. Split both the coding work and design work into sub-tasks where applicable and use subagents for the sub-tasks. Nest subagents where appropriate.

Treat prompts as an initial starting point for a discussion on what't to be done. Ask for more information about the what you're supposed to do to get a better result.

Ask for clarification when anything is unclear.

Ask for comfirmation on plans.

Ask for input on design/technology choices.
